## 当前可以独立进行的开发

已确认契约的纯功能模块可先编写：掩码方向、合法性、LOSO角色验证、指标公式、专家/Router形状、参数计数、严格设备门禁与日志格式。未冻结参数通过显式配置注入，不在函数内部偷偷填上科研默认值。

先为关键行为写测试，再实现模块；测试实际执行设备与状态单独记录。当前本地不运行神经网络计算。静态语法检查可执行，但不能替代 imports/API、数值、集成或 GPU 验收。

## 关键风险及解决路径

1. 课程示例存在候选值与教学简化：查原文并在决策表中确认。
2. 官方源码依赖绝对 models 导入：适配器需隔离命名空间，避免与本项目模型包冲突，并测试错误来源拒绝。
3. 预处理参考/标准化影响缺失隔离：定义并测试完整数据流，不仅测池化。
4. GitHub 提交不等于科研验收：README与报告逐级标记，未达L4不用于正式结论。
5. 共享服务器资源：只选授权GPU；资源变化时停止该次启动，不结束其他人的任务。

## 第一个 GPU 模块验收的预期内容

环境检查之后，用合成输入及真实官方权重核对严格加载、全部可用与单缺反事实、冻结状态、输出形状。这里不启动真实训练，不读取外层测试。失败时只修这一模块，成功后再进入真实数据的一步集成。

## 回滚原则

代码修复以新 commit 提交，不覆写既有实验目录。受影响结果标为失效并列出需要重新运行的范围。不要删除失败日志，也不要把旧配置下的结果重命名成新协议。
