## 授权和范围

2026-11-22，所有者明确授权助手在六讲零相位 FIR 与现有逐 Trial 因果
Butterworth 之间选择。选择六讲 6.2 的离线 FIR 路径，依据原文 PDF 物理页
245、248、258；这不是基于外层成绩选方法，也不声称 FIR 性能优于 IIR。

已核对的参考：MNE 1.13.2 `filter_data`/`create_filter` 官方文档，及固定

本次只决定滤波：250 Hz、0.3–40 Hz、FIR、零相位、Hamming/firwin、自动
长度和过渡带、reflect_limited 边界填充、单线程。先按连续段滤波再按 Cue
裁剪；不按 Trial 重置滤波。逐通道独立处理，不混合通道。

初始滤波决策之外的协议未自动批准。后续伪迹与重采样决策见文末；幅值额外
缩放、折内标准化、划分、增强、区域、预算、最终测试和统计仍待审。
候选配置 `approved=false` 不变。不要直接启动 prepare 或训练。

## 边界与失败策略

- 32766 run 起点作为硬边界，任何通道出现非有限值也构成共同边界。
- 只过滤完整有限段，原非有限值保留，后续 Trial 检查仍拒绝包含它们的输入。
- GDF 编码须先经过专用解析：见下述实测修正。未知编码仍报错，
  不裁剪、不插值、不删除异常 Trial。
- 有限段短于滤波核时明确失败，不能改参数或隐藏警告以通过。
- 缓存 manifest 记录实际段边界、缺失时间点数、滤波长度和系数哈希。
- 零相位处理使用同一段中的未来信号，是离线协议；不能宣称在线因果能力。
  同一 run 的相邻 Trial 会参与滤波上下文，但整名被试的 T/E 同角色；
  不允许再将这些 Trial 随机拆分成训练和测试。
- 伪迹标记不会自动成为滤波边界。因此即使之后删除标记 Trial，其波形仍可能
  影响同一连续段的相邻 Trial；此限制应在伪迹协议审查时说明。

## 验证与执行顺序

1. 新增 CPU 合成行为测试先失败（实现缺失），实现后运行。
2. 测试频率响应/零相位、run 隔离、通道独立性、NaN 间隙、短段拒绝、
   量程异常拒绝和候选配置仍被门禁拦截；再运行原有 GDF、数据统计测试。
3. 静态检查，提交新版本并通过 bundle 更新服务器。
4. 在服务器锁定环境重跑这些 CPU 测试；再检查真实记录完整连续段的量程、
   缺失编码和长度。原先四秒窗口有限性通过不能代替整段审计。
5. 获批其余预处理项后，生成新的缓存目录并重新做数据/GPU 集成验收。

原始下载、标签和未滤波窗口审计仍有效。任何旧预处理缓存、训练与验收报告
不得用作新 FIR 配置的证据；本项目尚无已验收正式缓存或模型成绩。
回滚使用旧代码/独立旧配置和新运行目录，不覆盖任何缓存；原始文件不变。

## A01T 实测编码后的修正

初版物理量程检查过于严格。服务器 A01T 实测在 8 个非首 run 起点各有 100 点、
22 通道全为 -32768：共 800 个时间点、17600 个通道采样值。另外存在 1872 个
-2048 通道采样值；它们是量化下端点，保留并计数，不能据此称为无伪迹。
反算数字编码最大残差为 2.2737367544323206e-13。

官方数据说明第 4 页明确 run 之间有 100 个缺失值，BioSig 可将其解码为 NaN，
关闭 overflow detection 时则保留负极值编码：
https://bbci.de/competition/iv/desc_2a.pdf

新解析限定实测 IV-2a 头部范围 [-2047,2047]、微伏标度和整数重建；只允许
[-2048,2047] 的信号编码及已核实的 -32768 间隙码。每个非首 32766 起点的
100 个采样必须在全部 22 EEG 上一致，其他位置不得出现 -32768。
确认间隙不与任一原始 Trial 的起点至 Cue 后四秒重叠后，才在内存副本中将
这些点标为 NaN；不缩短信号、不改事件索引、不丢 Trial、不写回 GDF。
FIR 沿这些间隙分段；manifest 保存间隙位置及原始窗口的端点计数。

这不是扩大物理量程容差：未知数字码、错误长度/位置、部分通道缺失、非整数
重建均拒绝。A04T 的间隙数量由真实 run 事件决定，不固定为 8。
当前证据只覆盖 A01T；其余 session 必须实测后才能验收。

   reflect_limited，不能直接混用。新增测试直接与 EpochsArray.resample 比较。
