# 研究假设与结果判定

以下是研究问题，不是已证明结论；原始H1/H2/H3的逐字表达以PDF为准。

1. 固定Trial及缺失数量，位置变化是否产生可重复的性能与路由差异？对应配对JS、Top-K切换与受控路由干预。
2. 显式Mask条件化是否在共同预算和统一验证选择下优于仅h的路由？比较Shared(h)与Shared(h,M)，报告被试级差值与不确定性。
3. 真实空间分组是否超越一般Mask信息和多个固定随机分组？比较Shared(h,M)、Spatial-EGS和随机区域重新训练。只出现激活差异不足以证明空间先验有效。
4. 未在训练或开发选择中使用的C3+C4联合缺失是否有泛化收益？先冻结全部对照与最终测试清单，再打开外层测试。

若空间增益不稳定、仅个别被试受益、机制干预无效或成本过大，应如实缩小论文主张。不得反复查看保留测试后修改超参数并仍称其为未见测试。新方案需要新的开发过程和清楚的探索/确认区分。
