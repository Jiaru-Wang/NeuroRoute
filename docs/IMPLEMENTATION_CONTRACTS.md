## 数据和掩码：1.3、2.1、6.2、6.3

B 为批量大小，C=22 为 EEG 电极数，T=4 为 patch 数，D=200 为 patch 长度和表征维数。

`[B,22,1000] → [B,22,800] → [B,22,4,200]`。M 为 bool `[B,22]`，True 表示可用。官方模型 mask True 表示隐藏，因此传入 `(~M)[...,None].expand(B,22,4)`。不能把缺失输入仅在模型输出后置零。官方源码在 CNN 和 FFT 之前替换隐藏 patch，完整反事实测试检查隐藏原始输入变化不影响最终输出。

主干输出 H `[B,22,4,200]`；电极向量 `v_bc = (1/4) Σ_t H_bct`；池化 `h_b = Σ_c M_bc v_bc / Σ_c M_bc`，h `[B,200]`。分母是每个样本可用电极数，全缺失输入拒绝。冻结主干包括参数、buffer 和 eval 模式。主干 no_grad；下游专家、路由、分类头参与梯度。

训练通道标准化候选：`x'_bc = (x_bc − μ_c)/σ_c`；μ、σ 只从当前 Fold 训练被试、所选 Trial、时间点拟合，使用总体方差，σ 下限 1e-6。每个 channel 独立，不混入隐藏电极。预处理不做跨通道 CAR；与官方 MAT 示例的差异必须写入论文。训练、验证、测试只读取各自角色的 EEG 缓存；原始数据缓存准备会审计全部18个session，不能把它称为未访问测试文件，但不计算外层测试模型性能或拟合跨分区统计。

严格 LOSO (Leave-One-Subject-Out，留一被试)：外层测试 f，验证 f−1（f=1时为9），其余7人为训练。T/E始终同角色；这是待批准确定性7/1/1，不是嵌套验证。

## 八个下游模型：3.1、6.5

专家 `E(h)=W2 GELU(W1 h+b1)+b2`，200→128→200。GELU 是 Gaussian Error Linear Unit（高斯误差线性单元）。MoE 为 Mixture of Experts（混合专家）。E0共享专家始终计算；候选专家使用真正按被选样本分派的执行路径。

Spatial-EGS：`a_bg=Σ_{c∈R_g}M_bc/|R_g|`，g=1..4。R_g 是四个非空不重叠电极集合，共覆盖22电极。`u=[h;M;a]` `[B,226]`，Router 226→128→7。a 是 M 的确定性变换，不增加新的观测数据；“空间先验有效”须由真实分组对随机分组重新训练证实。

`p=softmax(Router(u))`；S 为每样本 Top-K 索引；`w_e=p_e/Σ_{j∈S}p_j`（仅 e∈S 非零）。Spatial-EGS K=2，`z=h+ηE0(h)+(1−η)Σ_{e∈S}w_eE_e(h)`，η=0.5；分类头 Linear200→4，输出原始 logits，无 softmax。

这些是公式计算值；对应 GPU 自动化计数测试尚未执行。普通 MoE 残差 `z=h+ΣwE` 是显式待审融合方案。所有 Router 输入都补齐226维以避免输入槽数量造成参数差异。B0完整训练；其余变体使用同一已批准增强分布、相同身份键和每epoch顺序。分类头构造在各分支之前，使用相同 seed 时可获得相同初始化；不同结构不能声称每个参数都一一对应。

密集参考只用于输出/梯度比较和测速；稀疏未选专家 grad=None，密集未选专家可能 grad=0，AdamW 对两者的权重衰减语义不同。因此不能宣称两种训练过程逐步完全等价。

## 训练目标与路由诊断：3.2、5.1、6.6

交叉熵 `L_CE=−(1/B)Σ_b log softmax(logits_b)[y_b]`；y∈{0,1,2,3}。

Importance `I_e=(1/B)Σ_b p_be`，ΣI=1；硬 Load `F_e=(1/B)Σ_b 1[e∈S_b]`，ΣF=K。二者只统计候选专家，不统计E0。`L_imp=Var_e(I_e)/(mean_e(I_e)^2+1e−12)`，使用总体方差；`L=L_CE+λ_imp L_imp`。硬Load是不可微诊断，不能替代Importance损失。

日志中的 CE 和批内Importance损失按实际batch样本数加权。整分区Importance/Load从全部逐Trial路由重新汇总。训练指标描述更新过程中的预测，不是epoch结束模型在训练集重评。

归一化熵 `H=−Σ_e p_e log(p_e)/log(E)`，E是候选专家数。JS为两分布相对于均值分布的KL平均，使用自然对数，范围[0,ln2]；Top-K切换率 `1−|S_left∩S_right|/K`。同一 Trial、相同标签、相同缺失数量配对后报告。

K=1 时选中归一化权重恒为1，分类损失通常不给Router有效梯度；均衡项仍可能有梯度。η=1 时专门化分支被置零。检查按实际数学路径判断，不把这些可解释的零梯度误判为实现错误。

## 评价、干预和成本：6.4–6.7

Macro-F1 对固定4类分别算F1再平均，未预测类别为0；Balanced Accuracy 是4类召回率平均。必须收齐完整分区再算，不能平均batch F1。开发选择为三个独立条件的Macro-F1等权平均，禁止拼接预测后只算一个F1。同分保留更早epoch。所有基线使用相同规则。

干预时保持目标缺失输入及h固定，仅改变专家索引/权重或删除E0：固定均匀路由、所选权重均匀化、反转所选权重、专家ID循环置换、同Trial完整条件捐赠路由/排名权重、移除共享分支。捐赠条件、固定IDs、offset须在测试前批准。日志概率仍表示自然Router输出，`indices/weights`表示实际干预路径；不能把两者混为干预后的概率。

跨seed专家编号用条件×专家激活profile的余弦成本做匈牙利匹配，只是探索性对齐。专家输出相似度对同一批Trial的候选输出展平计算余弦；零向量标记，不能解释为已识别脑区。

MACs (Multiply–Accumulate，乘加次数) 统计主要Linear层 `in_features*out_features`，不包含CNN/FFT/非线性/dispatch；报告中注明下游范围，冻结主干参数另列。GPU延迟用CUDA Event、warmup和同步，分别测完整模型、缓存h后的稀疏下游、密集参考；参数少或Top-K不等于实际加速。

统计先在每被试内平均42/123/3407，再以9个被试配对。候选实现是2^9个符号翻转的双侧精确检验、被试bootstrap区间、配对效应量和Holm校正。符号翻转需要配对差值在零假设下的对称/可交换性；统计方案必须事先批准。它不消除LOSO折之间训练集重叠带来的推断限制。
