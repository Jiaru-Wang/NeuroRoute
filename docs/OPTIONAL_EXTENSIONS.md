# 候选扩展与第一阶段边界

第一阶段核心是冻结官方 CBraMod、原生缺失Mask、合法增强、线性/MLP/MoE公平比较、E0共享、显式Mask与空间覆盖条件化、Importance均衡和独立机制检验。

PDF 2.2 的 SCFC（空间条件特征补偿）、4.1 的 InfoNCE（对比学习目标）、知识蒸馏，以及更细空间编码均为后续候选。当前代码没有偷偷加入这些损失或额外训练阶段；不能把原生masked token说成缺失波形重建。配置也没有可直接开启未实现机制的开关。

TimeKD、Time-MOE、FSMoE是需要回到真实论文核实的参考线索，不在未核实作者、年份、具体公式、适用任务前生成正式参考文献。课程叙述不是证明其在EEG任务中有效的实验依据。

只有第一阶段真实诊断指出必要性后，才提出单独设计：明确公式与变量、梯度和教师冻结边界、完整/缺失视图的被试隔离、额外参数/训练预算、公平新增消融及新测试。SCFC/InfoNCE/KD未实现属于明确的范围决定，不是已完成模块。
