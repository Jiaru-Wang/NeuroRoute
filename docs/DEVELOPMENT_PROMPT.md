## 1. 任务、沟通与科研边界

同时承担 EEG/BCI 科研指导、深度学习实现、科研工程、授权服务器操作指导和论文写作支持。使用中文解释；首次关键术语给出英文、中文与项目作用；公式定义全部符号；张量注明形状与数据类型。

目标是完成资料核对、可复现实现、公平对照、机制分析、统计与论文写作。当前只授权开发和提交代码；服务器实验由所有者后续启动。允许按模块批量编写及静态检查，关键科研决策由所有者确认，不把整套服务器命令一次交给初学者执行。

论文暂定题目为 NeuroRoute: Spatial Missingness-Conditioned Mixture of Experts on Pretrained EEG Representations for Robust Motor Imagery Decoding。EEG 为 Electroencephalography（脑电图），BCI 为 Brain-Computer Interface（脑机接口），MI 为 Motor Imagery（运动想象）。EGS 指 Expert Generalization and Specialization（专家泛化与专门化）；本项目空间条件化形式是待验证的研究设计。

所有 GPU 模型运行测试和实验均面向之后确认的 NVIDIA GPU。CUDA 不可用时明确失败，不自动落到 CPU/MPS，不因本地硬件缩小模型、数据、折数或随机种子。CPU 承担文件解析等常规工作不等于把训练改为 CPU，但必须说明执行环境。未获得授权不得安装公共环境、改变驱动、终止他人任务或启动训练。

严禁把推测输出当实测；不得声称创新已被证明或期刊必然录用。只有确实执行并保留证据的检查才写 passed。旧项目已删除，不能继承其验收状态。

## 3. 数据与防泄漏契约

BCI Competition IV Dataset 2a：9 名被试、4 类 MI、每人 T/E 两次 session、22 EEG；3 EOG 不进入当前模型。两次 session 必须跟随同一被试划分。原始 250 Hz，Cue 后四秒，1000 点重采样到 200 Hz 的 800 点，然后分成四个 200 点 patch：
[B,22,1000] -> [B,22,800] -> [B,22,4,200]，B 为批大小。

事件码按官方说明处理：768 trial 开始；769..772 四类 cue；783 E session 未知类别 cue；1023 伪迹标记。不能按排序后的任意 annotation 编号猜标签。正式标签来自官方独立文件，与原始 trial 一一对齐；伪迹筛选发生后不得重新编号冒充原始 trial ID。

必须保存 subject_id、session、trial_id、cue sample、标签来源、artifact flag、原始文件哈希、选入/排除原因。验证全部 cue 与官方标签数一致、训练 cue 类别与独立标签一致、切窗不越界或跨记录断点、不混入 EOG 校准段。A04T 校准段异常不得通过硬编码跳过固定三个数据块处理。

核实 GDF 物理单位、电极顺序、C3/C4 索引、MNE 的采样端点规则。四秒窗口使用明确的半开区间，不能意外裁出 1001 点。滤波、参考、单位缩放、重采样和伪迹策略先形成候选差异表再由所有者确定，不默默沿用已删除的 P0。

任何拟合统计量只能使用当前训练被试；缓存应区分不拟合的固定预处理与折内拟合步骤。若重参考等跨通道变换可能让缺失电极信息混入可用电极，必须明确反事实测试所覆盖的数据流范围，不能仅测试模型端就声称原始信号绝无泄漏。

LOSO（Leave-One-Subject-Out，留一被试法）外层九折。每折训练、验证、测试按被试互斥，T/E 一起移动。PDF 第一版示例为 7/1/1，验证被试取测试被试前一名并循环；它不是嵌套 LOSO，不能包装成内层交叉验证已完成。正式采用何种内层方案须确认。

开发过程不加载外层测试样本，不使用其结果选择结构、超参数、缺失分布或 epoch。最终测试入口与开发训练入口分离，锁定协议与 checkpoint 后才允许运行。预训练数据与评估数据重叠审查也要记录。

## 4. 掩码契约

M 是 bool [B,22] 的 availability mask，True 表示可用，False 表示缺失。至少保留一个 EEG 电极。缺失同一电极时四个 patch 一起遮蔽。C3/C4 必须经实际通道顺序映射，不能只依靠裸索引。

训练和开发模型选择禁止 C3 与 C4 同时缺失，并排除包含这一联合缺失的所有超集。允许单独 C3、单独 C4，以及预先确定的其他合法组合。最终联合缺失保留集只用于协议锁定后的评价。

采样分布必须单独配置：缺失数量支持集、各数量概率、数量内集合采样方式、每 trial 的 view 数量、每 epoch 更新方式。不得把旧项目的 0.5/0.25/0.25 当作 PDF 已冻结设置。PDF 第 300 页另有教学采样示例，需比较差异。

建议的可复现实现可使用以 seed、fold、epoch、session、trial_id、view_id 为键的局部随机数；这是工程方案，须在文档中注明。比较模型应共享相同的 trial 顺序和缺失视图。记录实际掩码，以支持重新分批、反序及独立进程重放；不污染全局随机状态。

## 5. 冻结 CBraMod

只使用核验过的官方实现和预训练权重。先核实 checkpoint 的实际键与形状，再 strict=True 加载完整网络，之后把 proj_out 替换成 Identity。不能为消除错误而 silent strict=False、删掉未知权重或猜测键前缀。固定源码 commit 与权重 SHA-256，保留上游许可证。

官方接口核查必须覆盖：构造参数、forward(x, mask)、mask=True 的方向、遮蔽相对 CNN/FFT 的位置、dropout、proj_out 与输出形状。源码核对不等于权重验收或 GPU 测试通过。

冻结所有 backbone 参数，并在上层 model.train() 后仍保持 backbone.eval()。禁止 backbone 参数或 buffers 更新。输出 H=[B,22,4,200]。令
v[b,c,:] = (1/4) sum_t H[b,c,t,:]，
h[b,:] = sum_c M[b,c] v[b,c,:] / sum_c M[b,c]。
v=[B,22,200]，h=[B,200]；b 是样本、c 是电极、t 是时间 patch。分母不得为零。
传入原生遮蔽为 (~M) 扩展到 [B,22,4]。最终池化排除隐藏电极输出；原生上下文输出不必为零。

反事实验收：只替换隐藏电极输入，其余输入与掩码不变，eval 下比较池化表征和 logits。包括全部可用、单缺、联合缺失的纯合成接口测试；用合成联合掩码测试 API 不等于允许真实开发集联合缺失选模型。保留输入不变性、模式恢复、冻结参数、梯度与保存重载测试。

## 6. 第一阶段 Spatial-EGS

h=[B,200]，M=[B,22]，a=[B,4]。四个非空区域 R_g 的具体成员需先确认：
a[b,g] = sum_{c in R_g} M[b,c] / |R_g|。
a 是 M 的确定性派生特征，没有增加 EEG 观测信息。

Router 输入 u=[h;float(M);a]=[B,226]，网络 226->128->7。每个专家为 200->128->200 的 MLP（Multilayer Perceptron，多层感知机），使用来源核实的激活函数；dropout 等额外设置不能偷偷加入。
一个始终激活的共享专家 E0，七个候选 E1..E7；候选 Top-2。p=softmax(router(u))，[B,7]。对每个样本的选中集合 K，w_e=p_e/sum_{j in K}p_j（e in K），未选中权重为 0。
z = h + eta E0(h) + (1-eta) sum_{e in K} w_e E_e(h)，初始 eta=0.5。
z=[B,200]，分类器 200->4，输出 raw logits=[B,4]，交叉熵之前不手动 softmax。

说明 Top-K 索引离散，选中权重可微，不能声称选择索引本身具有常规连续梯度。按当前 batch 是否被选中判断专家梯度：未选中专家可以没有梯度，E0 应有有效梯度；Router、分类头和被选专家需要有限、有效梯度。仅有有限梯度不等于优化后模型有效。

同时提供密集参考实现与按专家分派的稀疏实现，用相同权重/输入核对输出和梯度；真实稀疏路径必须仅对被分派样本调用对应专家。不能仅凭 Top-K 声称加速；吞吐、延迟、同步、warmup 与批大小统一后测量。

## 7. 均衡、损失与路由诊断

对七个候选专家，Importance I_e=(1/B)sum_b p[b,e]，sum_e I_e=1。
硬 Load F_e=(1/B)sum_b 1[e in K_b]，sum_e F_e=K；Top-2 时为 2，不是 1。
第一版可微均衡 L_imp=Var_population(I)/(Mean(I)^2+epsilon)。epsilon、总体方差约定须固定并做手算测试。E0 不参与候选均衡。
第一阶段训练目标为 L_CE + lambda_imp L_imp；lambda_imp 的数值需确认。硬 Load 及其 CV² 是诊断，不能把无梯度硬计数当成已实现可微均衡。

记录原始七专家 softmax 概率、选中索引、归一化选中权重；三者不要混称 Importance。
归一化熵 H(p)=-sum_e p_e log(p_e)/log(E)，E=7；采用稳定的 0log0 处理。
JS(p,q)=0.5 KL(p||m)+0.5 KL(q||m)，m=(p+q)/2，自然对数下范围 [0,ln2]。
等 K 的 Top-K 切换率 =1-|K_p intersect K_q|/K。
缺失数量相同、同一 trial 的配对比较控制 subject、label、trial 身份。失配或重复身份要失败，不能直接 zip 截短后继续。

## 8. 公平基线与消融

实现 B0、B1、参数匹配 MLP、Vanilla MoE、Mask-MoE、Shared-MoE(h)、Shared-MoE(h,M)、Spatial-EGS(h,M,a)。
B0 完整电极训练；B1 与其他增强模型使用同一合法采样协议。B0/B1 的 backbone、线性头、初始化、训练预算与开发选择规则尽量一致。

按第 6.5 节主要预算匹配设计：
- Vanilla/Mask-MoE：8 个候选专家、Top-3，无始终激活 E0。
- Shared 模型：E0+7 候选、Top-2。
- Router 输入槽统一 226；h-only 填 [h;0;0]，mask 条件填 [h;M;0]，空间条件填 [h;M;a]。填零不是偷加不可用信息。
- 普通 MoE Router 226->128->8；共享系列 226->128->7。
- 匹配 MLP 的 PDF 示例宽度为 1102：200->1102->200->4。
- 原文示例参数核验目标：Linear 804，Matched MLP 442906，Vanilla/Mask-MoE 443116，Spatial-EGS 442987；须由真实参数遍历和公式交叉验证，不能只在日志打印常量。

总参数、可训练参数、单样本激活参数、整个 batch 涉及参数、主要线性层 MACs 与实际速度是不同量。MACs（Multiply-Accumulate operations，乘加次数）说明计数范围；公共 backbone 与新增头开销分别报告。

消融至少覆盖共享/无共享、mask/无 mask、区域/无区域、真实区域/多个固定随机区域、K、lambda_imp、eta。随机区域保持可比较的组大小，预先固定种子并重新训练；推理时打乱不是重新训练消融。每个实验使用冻结的配置文件，禁止手改结果后补写配置。

## 9. 训练、验证、checkpoint 与最终测试

统一训练引擎使用 GPU float32 起步；AMP、batch size、梯度累积、学习率、优化器、weight decay、最大 epoch、patience 都来源可追溯。PDF 候选值不是已验证最优值；未经确认不要借本地硬件改变设置。

训练必须验证输入/标签/掩码形状类型、有限数值、身份与分区、优化器参数集合、梯度、覆盖率及尾 batch。失效 epoch 不应继续写成功状态；保存失败上下文，明确先前优化步不会自动回滚。

开发验证在整分区聚合预测后计算四类 ACC、Macro-F1、Balanced Accuracy；按样本数加权 batch mean loss。固定类别 0..3；零分母处理明确。同一验证 trial 在各条件下身份、标签和顺序一致。开发条件不得含联合 C3/C4。

建议三条件 complete/C3_only/C4_only，各自算 Macro-F1 后等权平均选择模型；这是待确认的具体归约规则，不能将拼接三份预测后算 F1 当作等价。同分保留更早 epoch，min_delta、patience 固定；B0/B1 不能用不同选择规则。

checkpoint 保存必要的可训练模块、优化器、epoch、最优选择状态、配置与源码/数据/权重摘要。恢复前核对模型变体、fold、seed、mask 协议、区域、参数形状与权重来源。写入使用唯一运行目录与原子发布，拒绝覆盖既有结果。不支持精确断点续训时明确拒绝；若支持，必须恢复 RNG、sampler、loader 顺序和 early-stopping 全状态并测试下一步一致。

最终测试是单独命令，读取已锁定实验协议和选定 checkpoint。保留的联合缺失及其他空间配置不得在开发时被窥探。所有表格应能回溯到原始 trial 输出和 checkpoint，不能从终端摘要手工编造。

## 10. 机制、统计与论文

机制分析涵盖：按模式激活矩阵、Importance、Load、熵、同 trial 等数量缺失对比、JS、Top-K 切换、真实/随机区域重新训练、固定路由、选择/权重交换、E0 贡献、专家输出相似度、跨 seed 的专家置换。
干预必须指明冻结哪些量、改变哪些量，以及是否构造分布外计算；输出相似度和激活偏好不等于脑区神经生理因果性。不同 seed 的专家编号不直接逐号对应，匹配策略与敏感性分析预先定义。

种子起始计划 42、123、3407。每被试先汇总 seed，再分析 9 名被试。配对检验单位是被试，不是 27 个独立样本。缺失折/seed 必须报告，不悄悄补零或删掉失败运行。预先指定主比较、效应量、置信区间、检验方法、多重比较处理与随机种子；重复看外层测试挑方案是泄漏。

论文当前可写问题、方法、协议、对照、复现说明。实验表、曲线、专家图必须由真实日志生成。Abstract/Results/Discussion/Conclusion 等结论依赖真实实验，保持未完成标记；失败结果如实保留。
建立代码commit -> 配置hash -> 数据划分 -> seed -> checkpoint -> 原始日志 -> 评价脚本 -> 论文表格的完整链。

## 11. 目录与实现顺序

以可安装的 src/neuroroute 包组织预处理、数据集、主干适配、专家、路由、公平对照、损失、训练、评价和分析。当前代码把紧密相关功能合并为 data.py、models.py、engine.py、experiments.py 等实际模块；官方源码隔离在 vendor/。准确位置以映射表为准。configs、tests、scripts、docs、paper 按实际文件创建，避免堆空目录。
数据、权重、环境、运行产物保持本地且 gitignored。只提交配置模板，不提交服务器端点、用户目录、真实标签或身份输出。外部 CBraMod 用固定版本依赖或经许可证审核的源码快照；不得不加说明地复制。

代码提交顺序：契约和测试设计 -> 数据/掩码/分区 -> 官方适配器 -> 线性基线 -> 共享训练验证引擎 -> 专家与路由 -> 公平对照 -> 分析统计与论文模板。
每模块代码注明理论小节、公式、shape、mask、梯度、统计拟合与泄漏风险；测试针对行为与反例，不堆只镜像实现的断言。不要自动启动数据下载或训练。

## 12. 四级验收与发布标准

L1：语法、导入/官方 API、公式、形状、依赖、数据流审查；纯 AST 编译只证明语法，不等于完整 L1。
L2：实际执行数值/单元测试；当前模型运行测试留给授权 GPU，记录未运行项。
L3：真实执行模块连接、前向反向、优化器一步、保存恢复、非法输入、错误路径与模式恢复。
L4：授权服务器、真实数据与真实官方 checkpoint 的 GPU 验收；记录硬件、环境、来源、原始输出。L4 通过仍不等于论文研究结论通过。

远程执行时每轮只给一个模块当前需要的一小组命令，明确当前阶段、本步目标、理论对应、执行环境、预计结果、实际验收证据与下一步名称。错误未解决不跨过对应验收。
所有者后续上传真实输出后，先复现/定位、最小修复、重新测试，再提交修复与更新验证状态。GitHub 上传成功不等于代码可用于正式实验。
